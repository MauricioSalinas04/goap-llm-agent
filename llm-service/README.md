# llm-service

Servicio de inferencia del **módulo de razonamiento** — un modelo de lenguaje compacto optimizado para latencia, que evalúa situaciones sociales y genera intenciones de alto nivel.

Expone una API consumida por `unity-project` (ver la interfaz definida en [`docs/metodologia.md`](../docs/metodologia.md), etapa 2, S4–S5). Se implementa en la etapa 4 del [roadmap](../docs/roadmap.md), S9–S11.
